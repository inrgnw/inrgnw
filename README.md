# inrgNW

inrgNW, a Washington State energy management consulting business.

## Files

- `index.html` — website content
- `styles.css` — all styling; no framework required

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `inrgnw`).
2. Upload `index.html` and `styles.css`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the published site address.

## Before publishing

Change the placeholder email in `index.html`:

`hello@inrgnw.com`

to the actual business email address.

The site uses Google Fonts via CSS. If you want the site to work with no external font request, replace the font import with local/system fonts.
